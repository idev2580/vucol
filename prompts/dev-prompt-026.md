# Development Request Summary

## User request

Rename every `socl` occurrence in the project to `vucol` because `socl` collides with an OpenCL implementation name. Apply the rename to documentation and CMake as well (i.e. the whole repository).

## What to implement

- Rename the project/library identity from SOCL/socl to VUCOL/vucol everywhere: C++ namespace, include directory, CMake project/targets/options/package files, docs, README, examples, and tests.
- Rename filesystem paths: `include/socl/` → `include/vucol/`, `cmake/SOCLConfig.cmake.in` → `cmake/VUCOLConfig.cmake.in` (and generated `SOCLTargets.cmake` / `SOCLConfigVersion.cmake` references accordingly).
- Keep behavior identical: pure identifier/path rename, no API or logic changes.

## How to implement

- Case-sensitive mapping applied to file contents, file names, and directory names:
  - `socl` → `vucol` (CMake project/lib/target names, namespace `socl::` → `vucol::`, include paths `<socl/...>` → `<vucol/...>`, app/engine names, install-path examples, Doxygen exclude `socl::detail::*`, doc prose).
  - `SOCL` → `VUCOL` (CMake options `SOCL_*` → `VUCOL_*`, imported targets `SOCL::socl` → `VUCOL::vucol`, `SOCLTargets.cmake`/`SOCLConfig.cmake`, `find_package(SOCL ...)` → `find_package(VUCOL ...)`, `SOCL_ELEMENTWISE_ADD_SPV`, doc titles/prose, `SOCL GPU` log prefix).
  - `Socl` → `Vucol` (gtest suites `SoclApi` → `VucolApi`, `SoclBufferRanges` → `VucolBufferRanges`, prose `soclBLAS-style` → `vucolBLAS-style`).
  - `Simple Open Compute Library` / `# SOCL` title → VUCOL naming (e.g. README/docs title and `DOXYGEN_PROJECT_NAME`/`DOXYGEN_PROJECT_BRIEF`).
- Target/file renames: `socl` lib → `vucol`, `socl_tests` → `vucol_tests`, `socl_docs` → `vucol_docs`, `socl_elementwise_add` → `vucol_elementwise_add`, `socl_package_consumer` → `vucol_package_consumer`, `socl_shaderc_sdk` → `vucol_shaderc_sdk`, `PkgConfig::SOCL_SHADERC_PC` / `SOCL_SHADERC_*` vars → `VUCOL_*`.
- Source files in scope (contents): root `CMakeLists.txt`, `cmake/SOCLConfig.cmake.in`, `include/socl/*.hpp`, `src/*.{cpp,hpp}`, `examples/CMakeLists.txt`, `examples/elementwise_add.cpp`, `tests/BasicTest.cpp`, `tests/BufferRangeTest.cpp`, `tests/package-consumer/*`, `docs/*.md`, `README.md`, `AGENTS.md` title.
- Out of scope: past `prompts/dev-prompt-*.md` history files (immutable record), and generated `build/` / `CMakeFiles/` artifacts (regenerated by the developer).
- Per `AGENTS.md`: file changes outside `prompts/` require explicit user approval before editing, and no compile/execution is run in the agent environment — the developer rebuilds and runs tests after the rename.
